####################################################################################################
# DATABASE PHILOSOPHY
####################################################################################################

Database stores

Business Facts

NOT

Business Decisions

Business Decisions are generated by AI.

The database stores history.

The AI interprets history.

####################################################################################################
# DATABASE ENGINE
####################################################################################################

Development

SQLite

Production (Future)

PostgreSQL

The schema must remain database-independent.

Always use Django ORM.

Never write raw SQL unless absolutely necessary.
